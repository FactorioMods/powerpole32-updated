# Power Pole 32: Updated

Extends the big electric pole wire range to 32 tiles, making longer-distance power connections possible with fewer intermediate poles.

This fork retains the original range change for Factorio 2.1.24.

Requires Factorio 2.1.24 or later. Disable `PowerPole32` before enabling this fork. Required content and optional integrations are listed in the mod dependencies.
